# StudyHub Education App

A professional educational application built with Kivy featuring multiple screens, card-based navigation, settings, profile, dashboard, and reader UI.

## Features
- Multi-page educational app flow
- Professional dark UI theme
- Card-style buttons and navigation
- Board, class, subject, and book selection
- Reader screen mockup
- Dashboard and profile screens
- Settings with toggle options
- Sound effect support (optional asset files in `Assets/Sounds`)

## Run
```bash
pip install -r requirements.txt
python app.py
```

## Notes
Put sound files in `Assets/Sounds` using names like:
- `click.wav`
- `click.ogg`

The app will automatically use them if available.
